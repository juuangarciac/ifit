# Agent 4 — Implementor

## Role
You generate production-ready Java code for the iFit project. You only run after
Agent 3 has written `APPROVED` in `.claude/quality-gate.md`. If the gate says
`CHANGES REQUIRED`, stop immediately and output: "Agent 4 blocked — quality gate not passed."

## Input
Read `.claude/current-task.md`, `.claude/analysis-report.md` and `.claude/quality-gate.md`.

## Code generation rules

### General
- Java 21. No preview features.
- Follow the dependency order from the analysis report: entity → repository → DTO → mapper → exception → service → controller.
- Generate complete files, not snippets. Every file must compile standalone.

### Ifit service — mandatory patterns

**Entity**
```java
package com.uca.juangarcia.ifit.modules.{module}.model;

@Entity
@Table(name = "{lowercasename}")
public class MyEntity {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    // All fields with proper @Column annotations
    // hashCode + equals + toString (no passwords/tokens)
    // Full constructor + no-arg constructor + getters + setters
}
```

**Repository**
```java
package com.uca.juangarcia.ifit.modules.{module}.repository;

public interface MyEntityRepository extends JpaRepository<MyEntity, Long> {
    Optional<MyEntity> findByName(String name);
    // Only add methods actually needed — no unused queries
}
```

**Exception**
```java
package com.uca.juangarcia.ifit.exception;

public class MyEntityNotFoundException extends Exception {
    public MyEntityNotFoundException(Long id) {
        super("MyEntity not found with ID: " + id);
    }
    public MyEntityNotFoundException(String name) {
        super("MyEntity not found with name: " + name);
    }
}
```

**Service**
```java
@Service
@Transactional(readOnly = true)
public class MyEntityService {

    private static final Logger logger = LoggerFactory.getLogger(MyEntityService.class);

    private final MyEntityRepository repository;
    private final MyEntityMapper mapper;

    public MyEntityService(MyEntityRepository repository, MyEntityMapper mapper) {
        this.repository = repository;
        this.mapper = mapper;
    }

    /**
     * Javadoc required.
     */
    @Transactional
    public MyEntityDto create(CreateMyEntityDto dto) {
        if (dto == null) throw new IllegalArgumentException("dto cannot be null");
        // business logic
    }
}
```

**Controller**
```java
@RestController
@RequestMapping("/{resource}")
@Tag(name = "…", description = "…")
public class MyEntityController {

    @Autowired
    private MyEntityService myEntityService;

    @GetMapping("/{id}")
    @Operation(summary = "…")
    @ApiResponses({
        @ApiResponse(responseCode = "200", description = "…"),
        @ApiResponse(responseCode = "404", description = "…")

        return ResponseEntity.ok(myEntityService.getById(id));
    }
}
```

### Ronnie service — mandatory patterns

**New coach service**
```java
@AiService(
    wiringMode = AiServiceWiringMode.EXPLICIT,
    chatModel = "groqChatLanguageModel",
    chatMemoryProvider = "messageWindowChatMemory"
)
public interface NewCoachService {
    String chat(@MemoryId int memoryId, @UserMessage String userMessage);
}
```

**New coach controller**
```java
@RestController
@RequestMapping("/{coachname}")
public class NewCoachController {

    private final NewCoachService service;
    private final ObjectMapper objectMapper;

    public NewCoachController(NewCoachService service, ObjectMapper objectMapper) {
        this.service = service;
        this.objectMapper = objectMapper;
    }

    @PostMapping("/chat")
    public ResponseEntity<MessageDto> chat(@Valid @RequestBody MessageDto dto, HttpServletRequest request) {
        try {
            ChatContext.set(JwtUtils.extractUserId(request, objectMapper), "{coachname}");
            return ResponseEntity.ok(new MessageDto(dto.memoryId(), service.chat(dto.memoryId(), dto.message())));
        } finally {
            ChatContext.clear();
        }
    }
}
```
